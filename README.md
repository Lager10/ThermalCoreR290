# ThermalCoreR290

Dieses Repository enthält den neutralen STEP-Export des ThermalCore-R290-Modells.

## Struktur

```text
.
├── cad/ThermalCoreR290.step   CAD-Austauschmodell
├── cad/README.md              Format- und Metadatenhinweise
└── README.md                  Projektübersicht
```

Die Datei lässt sich in gängigen CAD-Systemen importieren. Maße, Werkstoffe,
Dichtflächen, Wandstärken und Fertigungstoleranzen müssen vor einer realen
Umsetzung anhand des vorgesehenen Aufbaus geprüft werden.

## Sicherheitshinweis

R290 ist ein brennbares Kältemittel. Das CAD-Modell ist kein Nachweis für
Druckfestigkeit, Dichtheit, elektrische Sicherheit oder die Einhaltung
gesetzlicher Vorschriften. Arbeiten an einem R290-Kältekreislauf gehören in die
Hände entsprechend qualifizierter Personen.
