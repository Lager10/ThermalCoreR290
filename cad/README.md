# CAD

`ThermalCoreR290.step` ist ein neutraler STEP-Export.

Die STEP-Kopfzeile enthält keine Personennamen, E-Mail-Adressen oder lokalen
Dateipfade. Erhalten bleiben lediglich technische Angaben zum Exportprogramm und
der Exportzeitpunkt.

Vor Fertigung oder Umbau müssen Maße, Einheiten, Werkstoffe und Toleranzen im
verwendeten CAD-Programm kontrolliert werden.
